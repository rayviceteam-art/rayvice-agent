# APPROVALS — human control

Agent khud kar sakta hai (low-risk): research, organize, analyze public info, draft post/reply, analytics, tests, branch/prepare code.

**Approval chahiye (hamesha):** external send, mass outreach, publish, delete, prod-DB, finance/purchase, paid AI, prod infra, irreversible.

Format: `ACTION REQUIRES APPROVAL [id]` + kya / kiske liye / kyu / hoga kya / risk.
Telegram: `APPROVE <id>` / `REJECT <id>`. `queue` se pending dekho.
Outreach default: NO auto-send — owner manually bhejta hai.
