# Product screenshots (feature spotlight posts)

Is folder me app ke **real screenshots** daalo — Sunday ke feature-spotlight posts
in ko branded frame me use karte hain (logo + gradient bar + caption).

## File naming (exact)

| File | Feature post |
|------|--------------|
| `scheduling.png` | Shift scheduling spotlight |
| `invoicing.png` | Invoice generation spotlight |
| `dashboard.png` | Dashboard spotlight |
| `rate-splits.png` | Split-rate accuracy spotlight |
| `compliance.png` | Records / compliance spotlight |

- Supported: `.png`, `.jpg`, `.jpeg`, `.webp`
- Best size: **phone screenshot ya wide screen shot, kam se kam 800px chauda**
- **Demo/test data only** — real participant names, NDIS numbers, phone numbers
  ya koi PII kabhi nahi (validators bhi block karte hain)

Agar file nahi mile → system automatically same content ka branded text card bana
deta hai, post rukta nahi. Screenshot add karke `git push` karo, agli Sunday wali
post me automatically use hoga.
