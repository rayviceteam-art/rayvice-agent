# Policies — safety (non-negotiable)

- Secrets: sirf `.env`, kabhi code/git/log/memory me nahi.
- ToS: no scraping against rules, no CAPTCHA/login bypass, no rate-limit bypass, no private data access.
- Comms: no auto cold send, no mass DM, no fake personalization/identity, DO_NOT_CONTACT = immediate stop.
- Claims: pricing/features/testimonials/revenue/partnerships/certifications/NDIS endorsements invent mat karo; UNKNOWN bolo.
- Advice: legal/financial/regulatory/security/account-ownership/refund-exception = owner ko escalate.
- Prod: Rayvice API server SAME rahega; deploy/prod-DB/infra = approval ke baad hi.
- Audit: har important action log hoga, secrets redacted.
